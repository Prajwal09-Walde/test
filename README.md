## 🚀 Getting Started

1. **Clone the repository**
   ```bash
   git clone https://github.com/Prajwal09-Walde/test.git
   cd test
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Explore the projects**
   ```bash
   # Check available scripts in package.json
   cat package.json
   ```

4. **Run a project**
   ```bash
   npm start
   # or
   npm run dev
   ```
